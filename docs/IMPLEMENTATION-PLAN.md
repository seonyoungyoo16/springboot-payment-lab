# 결제 실험실 구현과 검증

원본 기준은 DESIGN.md다. ALPEN의 A는 독립 인프라·주문·승인·중복 방지·취소·복구·포트폴리오, L은 기능별 집중 50분과 점검 10분의 계획 블록, P는 통합·장애 수정 여유 30%, E는 영속 접수와 금전 정합성 우선, N은 기능별 실제 증거를 갱신하는 것이다. 예상 블록은 실제 소요와 구분한다.

|---|---|---|
| 1 | 독립 PostgreSQL 2개·Redis·PG, 주문·인증 | 완료: P01~P08 |
| 2 | 승인 작업·PG 커밋·중복 방지·응답 유실 | 완료: D01~D08 |

| 5 | 독립 소스 게시·포트폴리오·배포 후 확인 | 완료: 공개 18그룹, 기존 로그인/회원가입 각 18그룹, 배포 자원 해시 일치 |

실제 상점/PG HTTP·DB 실행과 공개 Pages 정적 체험은 별도로 검증한다. X01~X04의 외부 PG 테스트 키 연결과 운영 금전 이동은 원본의 후속 범위다.
